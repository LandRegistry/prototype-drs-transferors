Information about the service

You can now provide an official search number for eligible charge transactions

Apply to register or update titles

You can use this service to make applications (with up to 50 titles) to:

  • update registered titles
  • register new titles (including transfers of part and new leases)
  • register lease extensions (close an old lease and register a new lease of the same property to the same tenant)
  • close leasehold titles (including merger applications)
  • register updates to existing multi-district titles
  • remove default Form A restrictions

Applications with more than 50 titles (DRS limit)

DRS can only accept applications with 50 titles or fewer. If your application has 51 titles or more, contact the Large Scale Services team.

Each application is considered separately. You cannot link applications.

When to submit your application by post

Multi-district title applications for transfers of part, new leases and lease extensions must be submitted by post.

If your application contains any of these titles, you must submit it by post:

  • closed title
  • caution title
  • scheme title
  • transfer of part for a multi-district title
  • transfer of part for a franchise title
