Expedite an application

Please note that you can only request an application to be expedited by using Application Enquiry service. Requests made via 'Reply to requisition' will not be processed, causing you further delays.

Specialist Support Services

Discover the range of expert-led services that are available to support those prior to submitting large-scale or complex applications or starting the development of residential estates. This can range from insider help and advice, to full application management and processing.
